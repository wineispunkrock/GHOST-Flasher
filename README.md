# GHOST-Flasher

Public browser-based installer for the private GHOST firmware project.

The page uses Web Serial and Espressif esptool-js to flash the Hoysond ESP32-S3 directly from Chrome or Edge.

## Current release

**GHOST v1.3.4**

The firmware source repository remains private. This repository intentionally contains only the public flasher and the release binaries required to install GHOST.
